# Vaccine_Drive_Managment_DB

A comprehensive Database Management System designed to streamline the process of vaccination drives.
It manages vaccine centers, employees, manufacturers, consumers, inventory, bookings, payments, and certifications efficiently.

# Project Overview

The Vaccine Drive Management System is a database-driven web solution designed to automate and manage the complete workflow of vaccination drives.
It helps different user groups — customers, employees, managers, and manufacturers — to efficiently handle registrations, slot bookings, vaccine availability, supply chain, and reporting.

# 🎯 Objectives

- Centralize vaccine drive data management.
- Reduce manual workload and improve efficiency.
- Ensure real-time availability tracking for vaccines and slots.
- Provide a secure and seamless user experience for all stakeholders.

# Database Design

The database is designed in 3NF/BCNF to ensure minimal redundancy and high efficiency.

**Key Entities**
- **Customers** → Manages customer info & vaccination status.
- **Vaccine Centers** → Stores center details & slots.
- **Employees** → Tracks staff & their roles.
- **Manufacturers** → Handles vaccine suppliers & stock.
- **Vaccines** → Manages types, pricing, and doses.
- **Inventory** → Maintains real-time vaccine availability.
